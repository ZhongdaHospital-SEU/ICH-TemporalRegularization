# Temporally Regularized Dynamic Graph Network for Ordinal ICH Deterioration

This project develops and externally evaluates a dynamic feature-graph model
for three-level GCS-based early neurological deterioration or death after
spontaneous intracerebral hemorrhage in intensive care.

## Design

- Development: MIMIC-IV v3.1, using the outline diagnosis set
  (ICD-9 431/432 and ICD-10 I61/I62). No additional diagnosis-code
  exclusion was applied.
- Same-institution source-shift external validation: MIMIC-III v1.4, ICD-9
  431/432.
- Geographic external validation: eICU-CRD v2.0, ICD-9 431/432 or ICD-10
  I61/I62.
- Prediction landmark: ICU hour 24.
- Predictors: information available through ICU hour 23.
- Outcome window: ICU hours 24 through 72.
- Models: static XGBoost, summary XGBoost, a GCS-slope-only logistic
  comparator, SeqOrdinal GRU, GRU-D, Transformer, DG-GRU, temporally regularized
  DG-GRU, nested logistic stacking, and time-reversed, time-permuted, and
  generic Laplace input-noise controls.

Every included patient, including a patient who died by hour 72, must have at
least two distinct ICU hours with valid total-GCS values between ICU hours 24
and 72. Sparse-GCS deaths are excluded; death does not waive the post-landmark
GCS eligibility requirement. Requiring the full 72-hour window would select on
future observation, so a live ICU discharge before hour 72 is retained when the
observed post-landmark GCS window still yields a classifiable grade. The
complete-follow-up subset is reported separately and is used as a prespecified
sensitivity analysis.

The operational endpoint is a confirmed GCS reduction in two adjacent hourly
medians relative to the pre-landmark maximum, or death within 72 h of ICU
admission, including a death that occurred after a live ICU discharge. It is
not presented as neurological deterioration independent of sedation or
ventilation. The outline's third Grade 2 component, verified unplanned
intubation after the landmark, cannot be reconstructed across the three
available database extracts; the endpoint is therefore labelled
`P020 = PARTIAL` rather than silently replacing it with ordinary recorded
intubation. See `outputs/study_protocol.md` for the full definition and
boundaries.

The third negative control is a generic Laplace input-noise arm, not a
temporal-smoothness penalty. It adds independent Laplace noise at scale 0.01
only to observed standardized time-series values; missing entries are not
noised and no temporal penalty is applied.

## Analytic cohorts

Cohort source counts, analytic counts, grade distributions, and Figure 1
exclusions must be read from rebuilt `cohort_flow.csv` and `cohort.csv`
artifacts. The previous README cohort table predates the strict P018 rule and
is withdrawn. The outline's draft sample sizes also differ from the rebuilt
audit and must not be reported as current counts.

The 210-predictor eligible development matrix, and the 23-variable core subset
used by the primary models, have no intersection with the audited
post-landmark or outcome fields.

MIMIC-III represents patients older than 89 years with a de-identification
sentinel: DOB is set to exactly 300 years before the first admission, so
computed age is 300 at that admission and can exceed 300 later. The sentinel
is recoded to 91 years to match MIMIC-IV's `anchor_age` convention, and an
`age_gt89` indicator is retained as a predictor. The eICU `> 89` category is
handled the same way rather than being collapsed to 89. The raw MIMIC-III
value is kept locally as `age_raw` for audit and is excluded from model inputs.

## Results status

`results/metrics.json` and the archived manuscripts predate the current
14-channel, three-database rebuilt cohorts and must not be cited. The formal
5-by-5 repeated cross-validation, five-seed averaging, 2,000-replicate
bootstrap and external transport have completed, and the results are in
`results/metrics_core.json`, `results/tables/` and `results/audits/`. The
site-level calibration update, endpoint/cohort sensitivity and 6/24/48-hour
landmark analyses are saved under `results/audits/`,
`results/sensitivity/` and `results/metrics_landmark{6,48}.json`. The
grade-specific detection and two-threshold ordinal recalibration analyses are
saved in `results/audits/strengthen_shortfalls.json` and
`results/audits/ordinal_recalibration.json`; the latter is regenerated by
`work/ordinal_recalibration.py`. Within-stratum model contrasts by
post-landmark documentation are saved in
`results/audits/stratum_model_difference.json` and regenerated by
`work/stratum_model_difference.py`. The
manuscript is rebuilt from `work/manuscript_content.py`; the previous DOCX
files are superseded.

Both Summary XGBoost and the temporal neural models use the same 23-variable
core subset of the 210 eligible pre-landmark static features. The core subset
was fixed before any outcome comparison and covers demographics, baseline and
summary GCS, vital-sign summaries, urine output, FiO2, RASS, and monitoring
intensity. An earlier draft described either all 210 variables or a
16-variable neural subset; neither describes the current formal run. The
negative cross-family result therefore cannot be attributed to the neural models
receiving fewer static features.

## Setup

Set `ICH_SOURCE_ROOT` to the directory that holds the MIMIC and eICU source
files. Derived cohorts, fixed-length sequences and generated outputs are not
distributed with this repository; they are rebuilt locally from the source
databases.

```powershell
py -3 -m pip install -r requirements.txt
```

## Reproduction

Build the three cohorts in parallel:

```powershell
py -3 -m src.ich_dynamic.build_cohorts --dataset mimic4
py -3 -m src.ich_dynamic.build_cohorts --dataset mimic3
py -3 -m src.ich_dynamic.build_cohorts --dataset eicu
```

Run the primary analysis with five parallel outer folds and seven parallel
bootstrap workers:

```powershell
$env:ICH_TORCH_THREADS='16'
$env:ICH_XGB_THREADS='16'
py -3 -m src.ich_dynamic.train_evaluate --models all --epochs 25 --folds 5 `
  --cv-repeats 5 --replicates 2000 --workers 5 --worker-threads 3 `
  --metric-workers 7
```

Run a temporal-regularization weight:

```powershell
$env:ICH_TORCH_THREADS='3'
py -3 -m src.ich_dynamic.train_evaluate --models dggru_tr --epochs 25 `
  --folds 5 --replicates 2000 --lambda-monotone 0.05 --lambda-smooth 0.02 `
  --tag lambda_m0p05
```

Run the complete lambda grid in parallel:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File work\run_lambda_grid.ps1
```

Run one sensitivity scenario:

```powershell
$env:ICH_TORCH_THREADS='2'
$env:ICH_XGB_THREADS='2'
py -3 -m src.ich_dynamic.sensitivity_analysis --scenario ett_censored `
  --epochs 25 --folds 5 --replicates 2000
```

Run all eight sensitivity scenarios in parallel:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File work\run_sensitivity_grid.ps1
```

Generate tables and figures after the metrics and sensitivity files exist:

```powershell
py -3 -m src.ich_dynamic.export_trajectories
py -3 -m src.ich_dynamic.make_tables_figures
py -3 -m src.ich_dynamic.make_manuscript
```

Run endpoint tests:

```powershell
py -3 -m unittest discover -s tests -v
```

## Directory layout

```text
configs/       Study parameters.
data/          Derived cohorts and fixed-length sequences.
outputs/       Protocol, manuscript, checklist, references, and deliverables.
results/       Metrics, predictions, tables, figures, and manifests.
src/           Cohort construction, models, evaluation, and reporting.
tests/         Endpoint unit tests.
work/          Reproducible helper scripts and working notes.
```

The `data/` and `outputs/` directories are produced locally and are not part of
this repository.

## Data and code availability

MIMIC-IV, MIMIC-III and eICU-CRD are available from PhysioNet to credentialed
users under their data use agreements. The present repository contains no
patient-level records and no derived per-stay tables; it contains the analysis
code, the fixed configuration, aggregate result tables, metrics and figures.
Aggregate tables by site report only hospital-level counts and calibration
summaries.

The manuscript text and the submitted DOCX and PDF files are not part of this
repository.
